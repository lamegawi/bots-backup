## IMPORTANTE: MANOS POLYMARKET (proxy de salida)

Polymarket **SOLO acepta operaciones desde tu IP** (la del PC, no Hetzner).

**Archivo**: `poly/codigo/proxy_pc.py`
**Puerto**: 8888
**Host**: 0.0.0.0 (escucha Tailscale)

**Cómo arrancarlo en tu PC Windows**:
```cmd
cd path\al\repo\bots-backup\poly\codigo
python proxy_pc.py
```

**Requisitos**:
- Tailscale activo
- PC siempre encendido (NO suspender)
- Ventana del proxy abierta
- Hetzner configurado para usar el proxy

**Si se cae el proxy**:
- Órdenes fallan con timeout
- Cerrar sesión Windows (Lock) está OK
- Suspender/apagar PC está MAL
